**Windows releases** (installer and portable zip) ship `libmpv-2.dll` from the
[shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake) build pinned in
`scripts/fetch-libmpv.ps1`. That build enables mpv's GPL parts, so **the Windows binaries as a
whole are distributed under the GNU General Public License, version 3 or later**; the complete
corresponding source is the vihpluh source of the release tag together with the mpv, FFmpeg, and
library sources at the revisions that build used (published in the repository above, under the
release tag the script pins). vihpluh's own code stays MIT and can be combined with any other
libmpv build.

**The bindings.** The `libmpv2-sys` crate (LGPL-2.1) is compiled into the executable on
every platform. vihpluh's complete source and build instructions are public, so anyone can
rebuild the executable against a changed copy of that crate.

**The Fedora package** bundles no playback code: it uses the system's `mpv-libs` and FFmpeg
packages, under the terms those packages carry.
